# Afristar Consulting website

A responsive, framework-free six-page website with an editorial redesign, scroll reveals, a reading-progress line, and reduced-motion support. Open `index.html` in a browser for a local preview. Upload the full folder to a static web host to publish it.

## Pages

- `index.html` — overview and service pillars
- `recruitment.html` — local and international recruitment, process, FAQs, and request form
- `hr-outsourcing.html` — outsourced HR and labour management
- `services.html` — HR, tax, strategy, risk, organisational development, and career coaching
- `about.html` — company, mission, values, leadership
- `contact.html` — contact details and enquiry form

## Contact forms

The static forms validate required fields and open an email draft addressed to `support@awtenterprize.com`. Visitors must review and send the draft from their email app. The forms do not submit to a server or CRM.

## Assets

The `assets` folder contains the supplied Afristar logos, favicon, and website photography. The career-coaching image flagged for licensing review in the handover has been omitted.
